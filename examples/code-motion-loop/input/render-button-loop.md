# One shape, six states: a render button loop

This example is a six-second square loop drawn by one motion page. One shape never cuts: it morphs from state to state while a cursor drives it.

The cursor clicks the Render button, and the button grows to fill the frame with a progress ring.

When the ring fills, the frame shrinks into a card for reel.mp4, marked Ready to post.

The cursor clicks Share on the card, and the card shrinks into a toast that says Link copied.

The cursor clicks the toast, and it grows into an end card with the product name, video-studio.

The end card shrinks back into the Render button, so the last frame is the first frame and the loop has no seam.

Every change lands on a beat of a synthesized score at 120 BPM: six seconds is three bars, with a bar every two seconds.
