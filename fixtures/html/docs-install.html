Installation

Widgetron runs on Node.js 22.13 or later and on any operating system supported by Node. The package is about 2 MB unpacked and has no native dependencies.

Install with npm

Add the package to your project with your package manager of choice:

npm install widgetron

Verify the installation

Run the doctor command. It checks your environment and prints a short report; the whole check takes under 5 seconds.

npx widgetron doctor
CheckExpected
node>= 22.13
ffmpegpresent

Tip: set WIDGETRON_LOG=debug to see every step the doctor runs.
