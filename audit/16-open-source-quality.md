## Recommended actions (all small)

1. **Versioning:** adopt semver now. Tag `v0.2.0` (the feature set is far past 0.1.0), start `CHANGELOG.md` (Keep a Changelog format) summarising Phases 0–8 plus the 2026-09-26 work, and bump `plugin.json` `version` on each release.
2. **`SECURITY.md`:** private reporting route; supported versions; threat model (ingested content untrusted, never executed; demo capture only against user-started URLs; keys only via userConfig → MCP env).
3. **`CONTRIBUTING.md`** (root): `pnpm install`, `pnpm hooks`, `pnpm check`, the architecture rules from `.claude/CLAUDE.md` that contributors must respect (no `bin/`, platform facts are data, no Sora, Remotion opt-in only), and links to `docs/contributing/*`.
4. **`.github/`:** bug report template asking for `/video-studio:doctor` output plus the failing tool result; feature request template; PR template with the `pnpm check` checklist.
5. **`plugin.json`:** add `repository` and `homepage`.
6. **`CODE_OF_CONDUCT.md`:** Contributor Covenant.
